# alunos-notas-medias
# 📚 Sistema de Cadastro de Alunos

Projeto desenvolvido em Python como parte dos meus estudos de programação.

O sistema funciona através do terminal e permite realizar operações básicas de cadastro e gerenciamento de alunos.

## 🚀 Funcionalidades

* Cadastrar alunos
* Listar alunos cadastrados
* Buscar aluno pelo nome
* Validar notas entre 0 e 10
* Armazenar informações de nome, idade e nota
* Menu interativo através do terminal

## 🛠️ Tecnologias utilizadas

* Python 3
* Listas
* Dicionários
* Funções
* Estruturas condicionais
* Estruturas de repetição
* Entrada de dados pelo terminal
* Módulos e importação de funções
